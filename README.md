# Introdução a Python

Este repositório contém o notebook da aula "Introdução a Python" para iniciantes em programação. O notebook apresenta uma contextualização teórica, exemplos de código executável, testes de mesa e atividades práticas para que os estudantes possam colocar os conceitos em prática.

## Competências a serem desenvolvidas

- Compreender o que é a linguagem Python e suas principais aplicações no mundo real.
- Desenvolver raciocínio lógico e capacidade de resolução de problemas utilizando algoritmos.
- Declarar e manipular variáveis, tipos de dados e operadores básicos em Python.
- Utilizar estruturas condicionais (`if`, `elif`, `else`) para tomada de decisão.
- Utilizar estruturas de repetição (`for`, `while`) para iterar sobre sequências.
- Escrever funções simples e reutilizáveis em Python.
- Ler, interpretar e depurar scripts básicos em Python.
- Aplicar as boas práticas de documentação e formatação de código.

## Formas de avaliação e coleta de evidências de aprendizagem

A avaliação será contínua, considerando as seguintes evidências:

- **Participação nas atividades práticas do notebook** – execução correta dos exemplos e completude das células de código propostas.
- **Testes de mesa** – análise do fluxo de execução de pequenos trechos de código para compreender como o Python interpreta as instruções.
- **Atividade final** – desenvolvimento de um script ou algoritmo simples utilizando os conceitos aprendidos. O estudante deverá codar a solução nas células indicadas no notebook.
- **Reflexões e comentários** – registros das principais dificuldades, descobertas e soluções encontradas durante os exercícios.
- **Entrega do notebook** – o arquivo `.ipynb` deverá ser entregue com todas as células executadas, incluindo as respostas das atividades.

O objetivo é coletar evidências não apenas do produto final (código funcionando), mas também do processo de aprendizagem, raciocínio e experimentação de cada estudante.

## Como utilizar

1. Acesse o notebook `aula_introducao_python.ipynb` (ou baixe o arquivo para executá-lo localmente).
2. Execute as células de código em ordem, lendo as explicações e observações que acompanham cada bloco.
3. Realize os testes de mesa propostos e registre suas observações.
4. Resolva as atividades práticas nas células indicadas, escrevendo seu próprio código.
5. Ao final, salve o notebook com todas as suas respostas e compartilhe conforme orientado pelo instrutor.

Bom estudo!
